从 CVE 抽 Post-Exploitation Action
CVE 通常描述 vulnerability → access。我们关心的是 access → action——攻击者拿到 access 后会做什么物理动作。

# CVE-2023-1748 
- **Description:** Certain Nexx smart home devices used hard-coded credentials. An attacker with unauthenticated access to the Nexx Home mobile application or the affected firmware can view credentials and access the MQ Telemetry Server (MQTT) server, allowing them to control garage doors or smart plugs for any customer remotely.
